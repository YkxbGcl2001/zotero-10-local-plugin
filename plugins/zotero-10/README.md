# Zotero 10 Plugin

This is the importable plugin directory. Both `plugin.json` and the legacy
`.codex-plugin/plugin.json` are provided. All runtime Skill resources are under
`skills/zotero-10`. Python 3.10+ and local Zotero Desktop are required.
For full installation instructions, see the repository root README and README.zh-CN.md:
https://github.com/YkxbGcl2001/zotero-10-local-plugin
